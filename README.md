# Probabilidade por pontuação

O código utiliza as pontuações dos campeões do Campeonato Brasileiro desde 2006 para calcular e gerar um gráfico da probabilidade cumulativa de um campeão ter uma pontuação menor ou igual a um determinado valor, variando de 0 a 100. Além disso, calcula a probabilidade de um campeão possuir uma pontuação menor ou igual àquela fornecida pelo usuário.
